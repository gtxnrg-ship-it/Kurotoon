# Kuru Shop Artwork

These assets are isolated crops from the Kurotoon/Kuru character reference board supplied for this Shop task. They preserve the source artwork; no replacement character designs were invented.

- `kuru_hero_reference.jpg`: low-resolution crop from the reference board, retained as a source reference; the Shop banner uses the isolated Happy sticker instead.
- `stickers/happy.jpg`
- `stickers/laughing.jpg`
- `stickers/love.jpg`
- `stickers/shock.jpg`
- `stickers/angry.jpg`
- `stickers/cry.jpg`

The source board is a flattened composite, so the expression crops inherit its limited source resolution. These six are wired to their matching catalog entries and used in both the cards and detail previews. The remaining catalog items still need their own isolated source crops before the artwork portion of the Shop can be called complete.
