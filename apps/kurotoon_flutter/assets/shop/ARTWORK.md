# Kuru Shop Artwork

No reference images are currently packaged in this directory. Previously added image files were removed because they had not been verified as faithful crops from the supplied reference board.

When the reference image is supplied again, crop the actual source artwork without redrawing or substituting it, verify each crop visually, and only then add the files and wire their paths into the catalog. Until then, the Shop uses its built-in animated icon fallbacks.
